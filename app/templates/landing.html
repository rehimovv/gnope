POGnope
Made for GNOME translators · works with any gettext project

Translate gettext .po files from Telegram

Send a gettext .po file to the bot, translate it string by string like in Gtranslator or Poedit, and get the finished file back with an updated header. No software to install — it works on any phone.

✈️Open in Telegram {{BOT_USERNAME}}
Opening Telegram in 3…
1
Send the file

Download a .po file from Damned Lies (l10n.gnome.org) or any project and send it to the bot.

2
Translate

The bot shows one string at a time with its context and notes. Just reply with the translation.

3
Download

Tap “Save file” to receive the translated .po file, ready to upload.

Features

  • Untranslated, fuzzy or all strings — you choose what to work on
  • Plural forms, context, developer notes and source references
  • Checks placeholders (%s, %d, {name}), keyboard shortcuts (_) and markup before saving
  • Header is updated automatically: Last-Translator, PO-Revision-Date, Language, Plural-Forms
  • Untouched strings stay exactly as they were, so diffs stay small
  • Interface in English, Turkish and Azerbaijani; files are deleted after 14 days
  • Free and open source (GPL-3.0)
